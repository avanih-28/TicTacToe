# Tic-Tac-Toe Game 🎮

A console-based Tic-Tac-Toe game where a human plays against the computer.

## What it does
- Human vs Computer gameplay
- Computer makes intelligent moves
- Win/loss/draw detection
- Clean console interface

## What I learned
- Logical thinking and control flow in Java
- Modular programming — breaking problem into functions
- Handling user input and game state

## Tech used
Java

## How to run
```
javac TicTacToe.java
java TicTacToe
```
